# sit_up_ln23_r2 — 実機開始分布+左右非対称DRで学習した版 2026-09-03

## 何が入っているか(ln22からの追加)

1. **開始バンク**: 実機30走行(9/2)のフレーム0×ロール±2.5度=90状態から
   学習エピソードの半分を開始。ハンドオフの立て直しを直接学習
2. **左右非対称DR**: 足ごとの接触摩擦・脚ごとのトルク上限を左右独立に抽選
3. 指令経路を実機と一致(参照ブレンド0.5秒)
対称化・前傾相・終端静止(打ち切り不要)は ln21/ln22 から継承。

## 優先2項目の測定(シム・生徒・ln22と同一条件)

**② 開始の膝突き出し(実機ハンドオフ状態から・各20試行) → 大幅改善**

```
        完走            膝逸脱(開始0.5秒)
ln22    11/20           中央16.0度
ln23    20/20 ★        中央13.1度
```

「開始直後に前に倒れる」の原因だった転倒がシム上で消滅。
膝の暴れは16→13度(消えたのではなく「暴れても立て直す」が主な獲得)。

**① 左ロール(各30試行) → ★悪化。左の偏りが再発**

```
        平均         左/右      3度超
ln22    +0.37度     12/18     12/30
ln23    -2.87度     26/ 4     16/30   ← 左偏り(偶然の確率0.03%)
```

原因の仮説: バンク(実機の状態そのもの)に実機の左癖が焼き込まれており、
学習で方策に移った。対策版(バンクの左右鏡像増強=9/2夕の依頼3)を学習中。
