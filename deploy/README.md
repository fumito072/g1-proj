# デプロイ方策カタログ(2026-08-19)

すべて**蒸留済み・実機観測のみ**(エンコーダ・IMU・エンコーダFK・脚オドメトリ・
直近3フレーム履歴=615次元)で、公式ゲイン(股100/膝150/足首40/腰200、
kd連動)・足首/腰トルク連続定格35N·m・関節速度制限内で動く。
全パターン、フルのドメインランダム化(摩擦0.4〜1.1 / 質量±10% /
重心±2cm / ゲイン±20% / トルク低下 / 遅延20〜40ms / 段高さ-1〜+2.2cm
(実物22cm対応) / 実測センサノイズ)を経て学習・蒸留してある。
sit系は座面の相対高さ(-4.7〜+1.0cm)もランダム化済み。

各フォルダの中身:
  policy.pt      TorchScript(観測正規化を内蔵。入力=生観測、出力=残差-1〜1)
  policy.onnx    同内容のONNX
  reference.npz  参照関節角・kp/kd・関節名・action_scale(0.7)
  meta.json      観測次元・来歴

制御則: 50Hzで q_target = ref_q[t] + action×0.7 をオンボードPD(500Hz)へ。
mode_machine=5、送信前に MotionSwitcher の ReleaseMode 必須(REAL_ROBOT.md)。

### sit_up_slow_r2 を非推奨にした理由(2026-08-25 実測)

`sit_up_slow_r2` の 85% は、8/24対策(椅子位置DR・開始位置ずれ・オドメトリ
ドリフト・実機較正摩擦)を入れる**前**の条件で測った値。現行条件で
deploy実体を測り直すと **8試行中5回が下降の途中(step 118〜131)で失敗**し、
理由はいずれも `hlead_late` = **参照より先に落ちる**(早落ち)。
つまり実機で期待される「ゆっくり」が現行条件では成立していない。
完走した3回は尻荷重 中央179〜254N でしっかり座れている(座り方自体は正しい)。

代替は現在学習中の `sit_up_ds_r2`(深座り×ゆっくり)。それが
`tools/gate_release.py` を通るまでは **`sit_up_deep_r2` を使うこと**。

### 3系統(2026-08-24。「椅子はロボットの真後ろ」運用に絞った版)

2026-08-24の実機で「骨盤が椅子に届かないまま着座動作を完了する」失敗が出た
(完走6走行が全て骨盤が足の真上のしゃがみで終わり、体重はハーネスが受けていた)。
その対策として、先行研究の要素を取り込んだ3系統を用意した。
**共通の変更点**: 椅子ヨーを振らず前後の後退距離へDRを寄せた / 立位→方策の
引き継ぎで起きる沈み込み・一瞬dampをDRとして注入 / 成功判定を
「完走」から「完走+HOLD 5秒の尻荷重」へ。

| フォルダ | 系統 | 中身 |
|---|---|---|
| sit_contact_r2 | ContactMimic | 参照の接触スケジュール(左足・右足・座面 × 先読み3点 + 座面接触までの残り時刻)を観測に追加。着座の報酬・制約を、膝角度由来の判定から**実測した座面接触ラベル**へ移した(既存判定より0.5秒遅く、猶予25コマがまるごとラベルのずれに食われていた) |
| sit_residual_r2 | ResMimic | 既存 sit_up_g1 を**凍結した基底** + その上の残差ヘッドだけを学習。残差は椅子相対位置(特権)を見る = object-aware residual。実機では蒸留で1本のMLPに畳んであり椅子は測らない(blind deployment) |
| sit_hybrid_r2 | 両方 | 接触スケジュール + 凍結基底 + 椅子相対の残差 |

観測次元: contact/hybrid は 215×3 = **645次元**(素の615に接触10次元/フレーム)。
residual は 615次元のまま。実機側は `meta.json` の `obs_extra.contact` を見て
`ObsBuilder` が自動で合わせる(`tests/test_obs_parity.py` が sim との一致を検証)。

推奨: **実機は sit_up_rc_r2 を既定に**(rbの後継。実機ログから同定した
関節摩擦入りのシムで再学習した版。logs/gap_map/ に同定の一次データ)。
rbは比較用に保持。2026-08-20 の実機ログから作った
開始状態バンク(引き継ぎ直後の前傾12〜20度+角速度〜1rad/s)込みで
追加学習・再蒸留した版(教師はβ=1.0・100試行92%)。sit_up_r2 は
その元になった版で、比較用にそのまま残してある。
もたれた見た目が欲しければ sit_lean_r2。
注意: 静的な前傾(傾き大・角速度ほぼゼロ)からの開始はどの方策でも
回復不能(実測0/10)。駆動前の姿勢チェックで弾くこと。
