# sit_up_ln21_r2 — 参照の左右対称化(左ロール対策・経路A) 2026-09-02

## これは何か

`ln20_r2`(実機14/15完走)の重みを親に、**参照の左右非対称を厳密にゼロ**へ
直して微調整した版。9/2実機の依頼1「参照のIKに左右対称拘束を(最優先)」への回答。

対称化の方法: 対称面を足の中点から実測(x=+0.034m)し、右脚=左脚の鏡像コピーで
強制(FK検証: 両足0.5mm)。股ヨー0.161rad等の左右差 → 全関節 0.000000 rad。
前傾相(+20度)はそのまま保存。

## ★実機でのA/B判定のお願い

シムのロール(-3.6度)は実機(-10.5度)の1/3しか再現していないため、
**実機で直ったかはA/Bでしか分からない**。同日・同設置で:

```
ln20_r2 → ln21_r2 → ln20_r2 → … 交互に各5本以上
記録: ①最大ロール ②股ロールactionの左右**和**(a[1]+a[7]。差ではなく和)
```

| 結果 | 意味 |
|---|---|
| ①縮小・②残存 | 実機側の非対称が主因 → 較正へ(関節ゼロ点・IMU取り付けロール・左右摩擦差) |
| ①②とも残存 | 較正が主因 |
| ①②とも縮小 | 参照対称化で決着 |

※方策の行動には非対称が残っている(股ヨー和+0.26等)。シムの結果ロールは
中立なので開始バンク等への補償と考えられるが、実機で①が残った場合の
容疑者リストに含めること。
