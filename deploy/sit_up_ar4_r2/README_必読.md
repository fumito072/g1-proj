## ★この版を作った目的は達成できていない

8/28の実機フィードバック「手が必ずクロスする(8本中5本)」「勢いが強すぎる」への
対策として作ったが、deploy実体で測ると:

```
              手の左右間隔(中央)   交差した回    骨盤の最大降下速度
ar1_r2           -0.045 m          18/20        0.63 m/s
ar4_r2           -0.010 m          17/20        0.51 m/s
参照が要求する値   +0.184 m           0          0.20 m/s
```

- **交差は 18/20 → 17/20 でほぼ変わらない。**
- 降下速度は 0.63 → 0.51 m/s(19%改善)。ただし参照の0.20 m/sには程遠い。

## なぜ効かなかったか

腕の交差禁止(`arm_cross_min`)は**教師では機能した**が、**蒸留で生き残らなかった**。

```
教師 85%(制約つきで学習・評価)
生徒 75%(合格ラインぎりぎり。ar1は生徒90%/教師90%)
```

教師は特権観測(体幹速度・接地フラグ)で交差を避けられるが、
生徒は615次元の実機観測だけでそれを再現できていない。

## 参照側に入れた修正(これらは有効なはず)

- **waist_pitch の22.5度の段差を修正**(19.63 → 1.45 rad/s)。
  全モーション共通の実在バグで、着座直後に kp=200×0.393rad = 79N·m(定格35)を要求していた
- 前へならえ(参照の手首間隔 0.184m 一定・左右対称)
- 終端で腕が静止(最後1秒の変化 0.0000 rad。ar1は0.0761)
- 下降1.4倍(参照 0.28 → 0.20 m/s)
