## 2. 中核の発見 — 性能の天井は方策ではなく参照(教師データ)が決める

このプロジェクト最大の教訓。RLの追加学習と参照修正の効果の対比:

```
RLを64M steps追加(8/25)         88% → 88%   1ポイントも動かず
参照に腕の軌道を入れる(8/27)      85% → 91%   学習0ステップ
参照に前傾相を入れる(8/28)        89% → 93%   学習0ステップ
参照を左右対称化(9/02)           93% → 97%   学習0ステップ(b10のみ4M)
```

実機からの指摘は毎回「参照の作り方」を指しており、直すたびに学習なしで効いた。
参照の欠陥だったもの:
1. **腕14関節が全コマ0.000rad**(振れ幅ゼロ)→ 方策が±0.7radの残差で釣り合いを
   即興し飽和(right_shoulder_yaw 59%)
2. **下降中の前傾が0度**(前傾の相が丸ごと無い)→ 方策は後傾でしか釣り合えず
   「背中から倒れる座り」に
3. **左右非対称**(股ヨーL+R -0.505radなど。元動画由来)→ 系統的な左ロール
4. **waist_pitchに22.5度/1コマの段差**(コマ244→245)→ kp200で79N·m要求(定格35)
5. **腕が394コマまで動き続ける**(終端静止の欠落)→ 実機の打ち切り運用の原因

## 4. ln23 の構成要素と、そこで見つけた5つのシム欠陥

ln23の学習には「実機ハンドオフをシムで正しく再現する」ことが必要で、
その過程でシム側の欠陥を5つ修正した。**これらの修正自体が資産**:

1. **開始バンクの高さ**: 着座フェーズは段の上(足の高さ0.244m)。床(z=0)に
   置くと椅子の台座に埋まり接触爆発で弾き上げられる(40msで骨盤+0.11m)。
   `sim_compare.place()` の規約に統一して解決
2. **スケジュール審判の猶予**: sit_late(座面到達の遅れ)・hlead(早落ち)・
   sit_tilt_bad(参照との傾き差)は**実機に存在しない審判**。実機が完走する
   ハンドオフ遷移をシムだけが殺し、学習信号ごと消していた。バンク開始の
   エピソードに2秒の猶予(物理の限界75度・横転・速度上限は猶予しない)
3. **指令経路の一致**: 実機の参照ブレンド0.5秒をシムにも(G1_CMD_START_RAMP)
4. **バンクはファイル名で解決される**: モーション名を変えるとバンクが黙って
   外れる(ln系はこれで開始分布を一度も見ずに学習していた)
5. **左右非対称DRの欠落**: 接触摩擦とトルク上限は左右共通の1スカラだった。
   G1_LR_ASYM で左右独立に(足ごとの摩擦・脚ごとのトルク)

修正の効果(実機ハンドオフ状態からのシム完走):

```
修正前   教師 0/20・生徒 0/20  (シムが実機の開始直後転倒を「再現」していたのではなく
                              シム自身が壊れていた)
修正後   教師14/20・生徒11/20 (学習前) → 学習後 生徒 20/20
```

## 7. 技術規約(再測定するときのために)

**左右対称性の測り方**(2回読み違えた末の確定版):
```
ピッチ系(股P・膝・足首P)   鏡像では L = R   → 差 L-R が0で対称
ロール・ヨー系             鏡像では L = -R  → 和 L+R が0で対称
```

**鏡像変換の検証は必ずヨー保存を含める**: クォータニオンの成分符号反転
(w,-x,y,-z)はヨー-90度の姿勢では**ヨーを+90へ反転**させる(lean/rollの式では
検出できない)。正: rpy分解で roll反転・pitch保存・yaw→π-ψ。

**開始バンクの仕様**: `motions/<モーション名>_start_bank.npz`(qpos(N,36)/qvel(N,35))。
ファイル名で自動解決・エピソードの半分に適用。高さは「足=min(ref_foot_z[0])」。

**回転符号は必ずFKで確かめる**(3回ミスした): 前傾+20指定が-20になった等。

**学習の停滞が「ぴくりとも動かない」場合は信号ゼロを疑う**: 42%×3回、62%×2回は
どちらも壊れたデータ(台座埋まり・ヨー反転)だった。遅い学習は毎回2〜4ポイント動く。

**プロセスをkillするときはPID/実行時連結パターンで**: 名前やコマンドライン部分一致は
自分や監視を巻き込む(2回事故)。

## 8. 未解決課題(優先順)

1. **左ロールの残り**(シム-2.5〜-3度・実機-5.2度): 現場の物理切り分け
   (椅子反転・機体180度)が最優先。シム側はシーンオフセット(x+0.034)の検証と
   非対称DRとの相互作用の調査が候補
2. **膝逸脱の さらなる縮小**(13度→): 現場依頼の「開始0.5秒の膝・足首逸脱
   ペナルティ」は未実装(合流動作と衝突するため保留中)。実機で②が確認できたら
   検討
3. **終端傾きの浅さ**(実機12.5度 vs 参照18度・着座◎2/15): 優先度引き下げ中
4. **位相合わせハンドオフ**(案): 現在は参照フレーム0から開始し方策が合流するが、
   現在姿勢に合う参照フレームから開始する方式ならハンドオフ遷移自体が消える。
   実機側コックピットの変更が要るため未着手
