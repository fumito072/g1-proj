> `実行ログがここに入る(logs/real/<日時>/)。ポータブル版では空で出荷。`


## 7.2 別系統ログ(`g1_実機ログ_20260826`)の解析結果 — 参考として重要

**実機走行18本(完走3・転倒15、成功率17%)。**

### いちばん重要な結論: 開始前のどの数値でも勝敗を予測できない

| 指標 | 完走3本 | 転倒15本 | 判定 |
|---|---|---|---|
| 開始傾き[度] | 3.9〜5.9 | 3.3〜7.2 | **重なる** |
| 開始L膝[rad] | 0.623〜0.854 | 0.605〜0.875 | **重なる** |
| 開始R膝[rad] | 0.629〜0.834 | 0.628〜0.850 | **重なる** |
| 開始足首τ合計[N·m] | 2.4〜10.1 | 1.8〜10.9 | **重なる** |
| 開始膝τ合計[N·m] | 27.0〜39.6 | 25.9〜39.7 | **重なる** |

完走した12:30(膝0.646/0.629、足首τ+2.4)と転倒した13:13(膝0.656/0.660、足首τ+4.9)は
**ほぼ同じ数値**。姿勢・速度・トルク・温度・電圧・接地チェックすべて調べたが分離できない。
→ **勝敗はログに写らない要因(物理設置か、方策そのものの余裕不足)で決まっている。**

### セッション中に潰した要因(いずれも真因ではなかった)

| # | 要因 | 実測 | 対策 | 結果 |
|---|---|---|---|---|
| 1 | **制御周期の低下** | 11:40=17Hz / 12:04=33Hz / 14:45=23Hz | CPUガバナ performance + **ACアダプタ接続** | 20.1ms=50Hz に固定。★**バッテリー駆動だと performance でも 800MHz に落ちる** |
| 2 | **開始時のトルク段差** | 跳び 0.46〜0.95rad / 18〜38N·m | action ランプ0.3秒 + 参照ブレンド0.5秒 | **0.053rad / 2N·m** まで低減。それでも転倒 |
| 3 | 開始姿勢のずれ | 参照から 0.06〜0.33rad | 「⤓開始姿勢へ」で 0.10rad まで | 成功率 1/7 → 2/4 に改善したが確定しない |
| 4 | 接地 | 足首が自由に回る回があった | 接地チェック(足首±0.05radの反力測定) | 15:29は両足「接地OK」で転倒 |

**PD保持ではどんな姿勢も保持できない**(sim実測: 参照開始姿勢は1.5秒で98度、
ほぼ直立でも1秒で29.6度)。PD保持は10〜15秒で膝が0.1rad沈む。

### 走行中に分離する指標

```
最大傾き   完走 20.8 / 26.4 / 32.8 度      転倒 34.6〜39.9 度(40度で自動DAMP)
                          ↑ 33〜35度の間に境界。33度を超えたら戻らない
参照軌道の最大傾きは 18.0 度 → 実機は毎回 3〜21度 余分に前傾する
```

**転倒はすべて本物の転倒**(DAMP時の傾き速度 +55〜+80度/秒 = まだ加速中)。
40度のしきい値を緩めても救えない。

### ログ形式と落とし穴
```
走行ログ/cockpit_YYYYMMDD_HHMMSS/
    run<NN>_<phase>_<方策名>.npz    rec(T×190, 列名は cols) + obs(T×615) + final
    run<NN>_設定.json               方策・kp/kd・関節名・開始温度・guard・ramp/blend
    イベント.log
監視記録/    1秒ごとのモード・傾き・トルク・ループ周期
解析/全走行_一覧.txt
```
`rec` の列: `t / fsm / phase_i / elapsed_s / tilt_deg / q29 / dq29 / tau29 / quat4 /
gyro3 / target29 / act29 / temp29 / dt_ms / ms_infer`。`obs` は**方策へ実際に入力した観測そのもの**。

> ★**`final` フラグを信用しないこと。** 12:32:00 は完走しているが `final=False`
> (完走直後に E-STOP すると記録が上書きされるバグが当時あった。同日修正済み)。
> **判定は `イベント.log` の「フェーズ完走」の有無で行う。**

### そのログ側からの学習への要望(RTX側でやること)

4. **膝の左右差**を報酬か終了条件に入れる(参照は0.00なのに実機で0.96まで開く)
