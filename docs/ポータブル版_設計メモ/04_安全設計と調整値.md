# 4. 安全設計と調整値

## 4.1 安全7層(`deploy/README.md` §5)

| 層 | 判定 | いつ効くか |
|---|---|---|
| 二重起動の検出 | 同じランナーが動いていないか | 起動時 |
| 立位保持の確認 | 沈み25mm / トルク飽和率0.85 | 方策を回す前 |
| 観測の事前検査 | 体幹ロール/ピッチ/ヨー・高さ・位置・関節 | トルクを出す前 |
| **予定軌道からの乖離** | シム20シードの帯×倍率 | 実行中(最優先) |
| 行動の飽和監視 | 飽和10%が10ステップ | 暴れ始める前 |
| 追従誤差 | 脚・腰が参照から0.6rad | 転びかけ |
| 転倒検知(**500Hz送信スレッド**) | 傾き0.61rad | 最終手段 |

原則:
- **中止=脱力にしない。** 立っているなら内蔵のバランス制御へ返す。保持したまま
  サービスを起動し、握ったのを確認してから kp を抜くので無支持がほぼ出ない。
  **すでに傾いているときだけ脱力**(0.80rad=46度超)
- **例外・Ctrl-C・端末クローズでも必ず脱力する。**
  `try/except BaseException/finally` + SIGINT/SIGTERM/SIGHUP ハンドラ + 送信スレッドの明示停止
- ~~B段(内蔵歩行)の最中は lowcmd 側の安全装置がすべて無効~~
  → **後ろ向き化でB段そのものが手順から消えた。今回の切り替えで得た一番大きな安全上の効果**

## 4.2 実機実験の手順(README §10)

1. **ハーネスを掛ける**(軽く支える程度。完全に吊ると地面反力が足りず前へ押せない)
2. ハードE-stopを手元に
3. 段の周囲を空け、落下時のマットを敷く
4. コックピットを起動(残骸は自動で片付く)
5. `pyflakes` と `parity_test` と シム を通しておく
6. **床で旋回だけ** 30度 → 90度 → 159.4度 と確認
7. **A段だけ**を回す。ログの「体幹姿勢の内訳」「立位保持の確認」「トルク飽和」を見る
8. 危ないと思ったら **■ 中止**

> **B段(段の上での旋回)は、床での旋回が確認できるまで行わない。**
> 段の上面は約 **0.72m × 0.40m** しかなく、踏み外すと落ちる。

## 4.4 ログの読み方(README §7)

`logs/real/<日時>/` に **100ステップごとに逐次保存**(強制終了しても残る)。

| ファイル | 中身 |
|---|---|
| `イベント.log` | 時刻つきの経過。切替・検査・中止理由 |
| `ログ.npz` | 毎ステップ: q / dq / qt / act / **obs(183次元)** / base_xy / base_z / v_world / rpy / gyro / odom_p |
| `config_使用値.json` `consts.json` `起動引数.json` | その実験の設定が完全に再現できる |

見るべき数値の例:
```
座標系合わせ: ヨー差 +109.0度 を補正 (参照 +105.3度 / IMU -3.7度)
体幹姿勢の内訳: ロール -3.1度 / ピッチ -0.7度 / ヨー -0.1度   ← 全部小さければ良い
立位保持の確認: 沈み 3mm (許容 25) / トルク飽和率 最大 0.42
A段 完走 376ステップ / 実時間 7.52秒 (参照 7.52秒 / 実効 50.0Hz / 遅延 0回)
  トルク飽和: ピーク 0.62 / 飽和した送信 0回
  予定軌道との乖離: 関節 0.42 / 高さ 0.31 / 傾き 0.55 (1.0で許容いっぱい)
```
加えて現行版は「**掴み→解放の窓 X.XX秒**」「**解放直後の傾き X度**」
「**飽和した関節 上位3つ**」を必ず出す。

## 4.5 設定変更の鉄則

座る速さや方策を変えたら、**必ず**次の2つをやり直す:
```
.venv/bin/python deploy/export_deploy_assets.py    # 定数・参照・地形
.venv/bin/python deploy/export_expected.py         # 予定軌道と帯(20シード)
```
やり直さないと実機が読む参照と予定軌道が食い違う。
ランナーは起動時に `ref_sit.npz` の **warp指紋**を config と突き合わせ、
違えば**動かずに終了する(終了コード2)**。
UIのボタンから変えれば、再生成 → 20シード検証 → 3D再生 が自動で走る(約30秒)。
**シムで落ちる設定になったときは3D再生をせず「★実機に出さないこと」を表示する。**
