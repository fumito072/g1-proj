# 3. 実機で踏んだ罠と対処(受け渡し以外)

出典: `g1_package/deploy/README.md` §4、`config.json` の注釈、
`g1_climbsit_runner.py` のコメント、`docs/実機実験報告_20260817.pdf`。

## 3.1 起動できない

| 症状 | 原因 | 対処 |
|---|---|---|
| 端末が一瞬で消える | `.venv` は `include-system-site-packages=false` なので `cyclonedds` が読めず `ModuleNotFoundError` で即死 | **PYTHONPATH に2つ**(同梱SDK + ユーザーsite)を通す |
| 「同じランナーが動いています」で起動拒否 | `pgrep -f` がエディタのサンドボックスを誤検出 | `ps -eo pid,comm,args` で **comm が python** のものだけ見る |
| 「コックピットは既に起動しています」 | 同上 | 同上 + 心拍ファイル `/tmp/g1_cockpit.alive` で判定 |

> **起動前に必ず `pyflakes` を通す。** 実機経路が `UnboundLocalError` で必ず落ちるバグを
> 埋めたことがあり、静的検査1回で防げた。**シムは `run_policy` を通らないので、
> シムが何度完走しても実機経路のバグは出ない。**

## 3.2 激しく動く(振動・異音)

| 原因 | 実測 | 対処 |
|---|---|---|
| **送信が50Hz** | 0.24rad/stepの階段。kp400で96Nmの蹴り | **500Hz送信スレッド** + 目標角の線形補間(SDK例が `control_dt_=0.002`) |
| **ヨーが106.6度ずれた観測** | 参照+105.29度 / IMU−1.30度。行動の**15.9%が飽和**(シムは0.2%) | 開始時にヨー差を測り、姿勢・速度・位置を回す |
| **速度の二重ヨー回転** | 補正済みquatで作った速度をさらに回していた | 除去 |
| **`torque_safe` が目標角を引き戻す** | 足首は50Nm/kp400で **0.125radで飽和**。飽和すると保持力が消える**正帰還** | 目標角を歪めない。学習環境と同じくトルクはドライバでクリップ、こちらは監視のみ |
| **脱力が「最後の指令値」を掴む** | 転倒後は指令値と実姿勢が離れており、元の姿勢へ引き戻そうと暴れる | **実姿勢**を掴む |
| **ジギング(毎ステップ符号反転)** | 主要関節で **47〜53%**、振幅0.06〜0.09rad | 行動に1次ローパス(係数0.5)。学習側は行動変化を罰する項があるので意図は壊れない |

## 3.3 何もしていないのに唸る(実機で60分継続)

**残ったランナーが500Hzでlowcmdを出し続けていた。**

- 送信スレッドを `daemon=False` にしたので、終了処理で `stop()` を呼ばないとプロセスが死なない
- `kp_scale=0` でも `kd`(脚12)を出すと粘性トルクが内蔵制御に逆らう → **待機中は kd も 0**
- 内蔵制御へ返したら**送信そのものを止める**

確認: `ps -eo pid,etime,args | grep -E "climbsit_runner|compare_sim_real" | grep -v grep`

## 3.4 観測が壊れる(5点が同時に壊れていた)

| # | 症状 | 実測 |
|---|---|---|
| 1 | 体幹ヨーが106.6度ずれる | 参照+105.29度 / IMU−1.30度 |
| 2 | 参照位相が実状態と無関係に進む | **未解決**(構造的な差) |
| 3 | 骨盤高さが `ref_ground` に依存 | `ref_ground` は**参照の骨盤xyの真下**で足の下ではない。段で **+0.21m** ずれ |
| 4 | 接地フラグが常時ゼロ | 貫入0だとMuJoCoが接触を作らない。**2mm沈めて 0→60/60** |
| 5 | 速度の二重ヨー回転 / odomのXY | odomは±2.7m/sスパイクと0.35m漂流 → **脚オドメトリの積分に統一** |

### ★接地フラグの重要な性質(実機で素直に作ると学習と違う観測になる)
学習環境の `_contact_state()` は `robot_bodies` に world(床)を含むため、
**床との接触を永久に数えない**。実測で参照の fr0-60(床の上)は on=[0,1]/60コマ、
fr300-375(段の上)は on=[76,76]/76コマ。
つまり `on[]` の意味は「接地」ではなく **「足が段・座面に触れているか」**。

## 3.5 変化率制限が参照を削る

固定 0.35 rad/step にすると**参照そのものを削る**。実測で参照の1ステップ変化は
最大 **0.610 rad**(左膝 fr80→81)、0.35超えが3箇所。
→ 制限は「参照自身の変化 + 余裕」にし、**方策の残差だけ**を抑える。
(kp=400では0.61radの階段は20msで240Nm相当になり、実機で大きな音が出る)

## 3.6 その他の実機発見

- **fr0 は遊脚が約5cm浮いている。** 実機12:00は fr0 を押し付けてトルクが上限の**2.44倍**、
  **32mm沈み**、その姿勢のまま内蔵制御へ返して大きな音になった
  → `first_flat_stance()` で「両足のFK高さが揃う最初のコマ」から始める
- **着座の開始姿勢は実機立位と 股ヨー約21度・肘約57度ずれている。**
  接地したまま股ヨーでねじると「ががが」と鳴り後ろへ重心が逃げる
  → 股roll/yaw と腕は**いまの立位の値を全コマに載せる**(`_SIT_PIN`)
- **腕をピン留めすると観測が分布外になる。** 実機15:33の解析で、腕を歩行姿勢に
  ピン留めすると両肘の観測が学習分布から常時 **+3σ** 外れる(obs[31]/obs[38])
  → 既定は「腕は本物の参照姿勢へ動かす」。進入前に公式 arm_sdk ブレンドで
  1.5秒かけて腕を参照始点へ移す(`腕を事前に合わせる: true`)
  ※ arm_sdk のブレンドは腕14関節+**腰3関節(12-14)**にかかる(実機15:53)
- **着座では高さ推定が破綻する。** 尻が体重を受けるため「足が接地している」前提の
  高さ推定が成り立たず、0.8秒付近で推定が **1.10m へ跳ぶ**(08-17 15:41)。
  この誤作動で監視が中止し、退避処理が座りかけの姿勢から立位へ引き戻して「変な動き」になった
  → **着座域(参照コマ45以降 または 骨盤高さ0.85m未満)での中止は立位へ戻さず、
    最終着座姿勢へ2秒で寄せて座らせて終える**
- **着座の下降でα=0.5のローパスは有害。** 位相遅れで後傾を止められない
  (シム実測: α0.5→後傾24度・完走9/12、**α1.0→後傾9度・完走12/12**)
  → 着座は平滑化係数 **1.0**(フィルタ無し=学習と同条件)、段差登りは学習時からβ0.5なので **0.5**
- **後傾ドリフト(実機14:31)**: 関節は予定±3度で追従しているのに**体だけが約−0.5度/step
  後傾**し、下降開始とともに18度で中止。初期条件ではなく**実機の重心が模型より後ろにある
  系統誤差**とみられる → `probe_backdrift.py` で基部に一定後傾トルクを加えて再現し、
  足首ピッチのバイアス補正(±1〜3度)の効き目を掃引できるようにした

## 3.7 2026-08-17 に特定した10件(実機実験報告PDFより)

全11試行(A段9回・C段2回)。午前は起動と観測系の不具合で方策がほぼ動かず、
午後には **15:20のA段で一歩目の踏み込みに成功**(右足上げ高さ 実測0.336m / 参照0.337m)、
**15:41のC段で着座の下降動作まで到達**。

| 時刻 | 症状 | 原因 | 対処 |
|---|---|---|---|
| 09時 | 起動して端末が即消える | venvからDDSライブラリが見えない | PYTHONPATHにユーザーsite追加 |
| 10:05 | 8ステップで「ループ遅延」中止 | 500Hz送信が時刻表からドリフト | 絶対時刻への割り付けに変更 |
| 10:07 | 腕の整定誤差で開始できず | 想定内の偏差 | 整定判定を脚・腰と腕で分離 |
| 10:26 | 開始直後から方策が暴れる | 観測の体幹ヨーが106.6度ずれ | 開始時にヨー差を自動測定し全量補正 |
| 11:48 | 「ぎぎぎ」と鳴り徐々に脱力 | トルク保護が目標角を引き戻す正帰還 | 監視のみに。学習と同条件へ |
| 13:20 | 起動を拒否される | 二重起動検出がエディタの子プロセスを誤検出 | 実行ファイル名で厳密判定 |
| 13:44 | 69ステップで誤中止 | 予定軌道監視の関節許容が実機の定常誤差より狭い | 関節0.45radへ緩和。バランスは高さ・傾きで監視 |
| 14時 | 何もしていないのに唸る | 中止済みランナーが残留し500Hz送信継続 | 起動・終了時の自動片付け + 送信スレッドの確実な停止 |
| 15:22 | 確認待ちがUIから解除できない | stdinを停止監視と奪い合い | SIGUSR1 + ファイルの2経路に変更 |
| 15:41 | 着座後に立位へ引き戻す動き | 着座域でも立位復帰の退避が走る | 着座域では座らせて終える |

体幹ロール3.1度 / ピッチ0.7度 / ヨー残差0.1度 / 骨盤高さ誤差0.020m /
水平位置誤差0.000m / 脚・腰関節差0.072rad / 沈み3mm / トルク飽和率0.42。
