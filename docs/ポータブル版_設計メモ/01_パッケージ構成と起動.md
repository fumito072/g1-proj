## 1.3 起動の流れ

`起動.py`(GUI/CLI両対応)が:

1. `g1_package/.venv` を virtualenv で作る
2. `requirements_portable.txt` を pip 導入(**初回のみ・ネット必須・約2GB**)
3. import 確認
4. `.venv` の python でコックピットを起動(`PYTHONPATH` に同梱SDKを追加)

完了は `.venv/.portable_setup_done` に記録し2回目以降は省略。
コックピットのボタンは `g1_climbsit_runner.py` などを**同じvenvのpython**で
サブプロセス起動する。パスはすべてパッケージ内の相対解決なので解凍場所は自由。

### 必要要件

| 何 | 内容 |
|---|---|
| OS | Linux (Ubuntu 22.04/24.04想定) |
| Python | 3.9以上 |
| OSパッケージ | `python3-venv python3-tk libgl1 fonts-noto-cjk` |
| ディスク | 展開156MB + 依存約2GB |
| 実機接続 | 有線LANで 192.168.123.x に直結。NIC名を起動画面で指定(既定 `eno1`) |

GPU不要(torchはCPU版)。学習を回す場合のみ手でGPU版torchに入れ替える。

## 1.4 コックピットUI(`real_mac/tools/g1_cockpit.py`)

1ウィンドウに 3Dツイン(MuJoCoオフスクリーン→Tk埋め込み) / LiDAR上面図・側面図
(`rt/utlidar/cloud_livox_mid360` @10Hz、高さ色分け) / サーボ操作パネル を統合。

主要ボタン群:

- **■ 中止(内蔵へ返す)** / **▶ 続行(確認ゲート解除)** ← パネル先頭に固定
  (1080pで画面に収まりきらないため、非常停止をスクロールの先に置かない)
- ロボットモード: ゼロトルク / ダンピング / ロック立位 / 床へ着座 / バランススクワット /
  **歩行開始(自動)** / モード解放 / AIモード復帰 / **FW診断**
- シム検証: 通し / 後ろ向きに登るだけ / 座るだけ(実時間で3Dビューに再生)
- 座る速さ: 標準1.00 / ゆっくり0.70 / もっと0.50 / うんと0.35
- 座り方: 標準 / ふわっと、方式: 内蔵 / 学習 / ハイブリッド
- 実機: 通し実行 / 登るだけ / 座るだけ
- 旋回(予備): 30度 / 90度 / 159.4度 ← **通し手順には入らない。段の上では絶対に回さない**
- 差を調べる: 設定の比較 / 実機を観測 / IMU位置と遅れを測る / 全タスク停止
- 全身動作(内蔵バランス制御): モーション一覧・シーケンス・デモ停止

仕掛け:
- **心拍** `/tmp/g1_cockpit.alive` を1秒ごと更新。「プロセスあり + 心拍が古い」を残骸と判定して片付ける
- UI内実行(`subprocess.Popen` + パイプ)。**別端末は開かない**
- 中止ボタン: SIGTERM → 3秒 → SIGKILL → **FSM 0(ゼロトルク)**
- 3D表示は `logs/sim_stream.npz` 経由。**npzは必ず閉じる**(fd漏れで2回目以降描画が壊れる)、
  **レンダラは1回だけ作る**(GL資源が尽きる)

## 1.5 同梱アセット

### `chair2_asset`(2026-08-07 スキャン)
動画から Apple Object Capture で再構成した「シート+ジョイスティックアームレスト+ベース箱」。
- 単位m / Z-up / 底面z=0、bbox **0.80 × 1.11 × 1.23 m**
- スケールはベース上のカーペットマット(実寸0.50m/辺)で較正、**誤差~0.5%**
- テクスチャ付きOBJ/GLB(10万面)+ CoACD凸分割コリジョン64個
- MuJoCo 3.3.7 でロード確認、8秒落下テストで水平静止(接地誤差4mm)
- 質量は暫定80kg(`density` で調整可)。底面は撮影不可のため平坦性±2cm

### `real_mac/deploy/pipechair_v2`(2026-08-07 の旧世代)
**別系統**の配備パッケージ。ONNX(obs145→action29)、Mid-360エレベーションマップ利用。
- `g1_climb_A4b.onnx` — CPU1スレッドで **0.03ms/推論**(50Hz予算の0.15%)
- シム検証 climb 100/100・転倒0・トルク超過0%
- 旋回着座 `g1_turnsit_B4.onnx` は成功率70%で実機基準90%未達のため**使用禁止**として同梱
- パリティ jax→numpy 2.6e-06 / numpy→ONNX 1.6e-06
- **Mid-360は下向き20〜30°で機体固定**(水平取付だと段も座面も垂直FOV外=原理的に見えない)
- 段階投入 P0関節順序照合 → P1吊り下げ → P2平地 → P3ハーネス登攀(18/20で合格) → P4
