## 10.2 中身の形式(全ファイル共通)

PyTorch の `torch.save` 辞書。`torch.load(path, map_location="cpu")` で開く。

```
{
  "net":  { log_std(29), pi.0.weight(512,183), pi.0.bias(512),
                         pi.2.weight(256,512), pi.2.bias(256),
                         pi.4.weight(29,256),  pi.4.bias(29),
            vf.0.weight(512,183) … vf.4.bias(1) },     # 方策13テンソル
  "norm": { mean(183), var(183), count },               # 観測の正規化(★方策に同梱)
  "obs_dim": 183, "act_dim": 29,
  "motion": "sit_only", "steps": …, "mean_return": …, "mean_len": …, "fail_rate": …
}
```

- 方策ネットは **MLP 183 → 512 → 256 → 29**(価値関数 `vf` も同形で 256 → 1)。ガウス方策(`log_std`)
- **観測の正規化 `norm` が方策ファイルの中に入っている**ので、`.pt` 単体で推論の再現ができる
  (`deploy/artifacts/norm_sit.npz` はこれを書き出したもの)
- 出力は**残差**。実際の目標角は `目標角 = 参照 + 行動 × 0.70`(`action_scale`)、制御 **50Hz**

## 10.3 性能の実測(20シード / 下降2.12秒 = 0.70倍速)

| | `sit_v1_best_S` | **`sit_soft_v2`** |
|---|---|---|
| 座面ピーク荷重 | 1089N = **体重の3.17倍** | **557N = 1.62倍** |
| 参照より沈む量 | 64 mm | **15 mm** |
| 完走(20シード) | 20/20 | 20/20 |
| 遅くできる限界 | 0.65倍まで | **0.30倍まで20/20**(遅いほど荷重も下がる。0.30倍で456N) |

`sit_soft_v2` は `sit_v1_best_S` から **4.01Mステップ追加学習**したもの。足した報酬は
`r_zsit`(参照より下へ沈まない・0.30)/ `r_seat`(座面荷重の超過分を罰・0.30)/
`r_vzsit`(参照より速く落ちる分を罰・0.20)と、`r_sit` の発動条件の修正
(従来は膝角度判定で **0.90秒早く**尻荷重を要求しており「早く落ちるほど得」になっていた)。
詳細は [05_方策と参照モーション.md](05_方策と参照モーション.md) §5.5。

## 10.4 使うときに一緒に要るもの(このフォルダにはコピーしていない)

`.pt` だけでは実行できない。元パッケージの次が対になる:

| 必要なもの | 場所 |
|---|---|
| 参照モーション(時間軸伸長済み) | `g1_package/deploy/artifacts/ref_sit.npz`(325コマ・warp指紋つき) |
| 予定軌道の帯(20シード) | `g1_package/deploy/artifacts/expected_sit.npz` |
| 定数(kp/kd・トルク上限・関節順) | `g1_package/deploy/artifacts/g1_deploy_consts_v3.json` |
| 元の教師データ | `g1_package/motions/sit_only.json` / `sit_only_clean.npz` |
| 実行系 | `g1_package/deploy/g1_climbsit_runner.py` / `config.json` |

**方策を差し替えたら必ず** `export_deploy_assets.py` と `export_expected.py` を
やり直すこと(参照と予定軌道が古いままだと、ランナーが warp指紋の食い違いを検出して
**終了コード2 で動かずに終わる**)。UIの「座り方」ボタンから変えれば自動で走る。

## 10.5 読み出しの例

```python
import torch
d = torch.load("方策_座る/sit_soft_v2.pt", map_location="cpu", weights_only=False)
print(d["obs_dim"], d["act_dim"], d["motion"], d["steps"], d["fail_rate"])
mean, var = d["norm"]["mean"], d["norm"]["var"]        # 観測183次元の正規化
W1 = d["net"]["pi.0.weight"]                            # (512, 183)
```

推論は `g1_package/rl/ppo.py` の方策クラスに `net` を `load_state_dict` して、
観測を `(obs - mean) / sqrt(var)` で正規化してから通す(実機・シムとも同じ経路)。
