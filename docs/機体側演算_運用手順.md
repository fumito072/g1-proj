# 機体側コンピューターでの演算（オンボード実行）

方策推論・50Hz 制御ループ・500Hz 送信を、操縦PC ではなく**機体側コンピューター
（Jetson / ARM64）**で実行し、DDS をループバック化して遅延・確実性を上げる手順。
PC はブラウザによる監視・操作 UI として残る。

## 1. 構成

```
モーションコントローラ ⇄(ループバックDDS)⇄ RealRobot ⇄ Engine(50Hz + 方策推論) ⇄ Handler(HTTP)
                                                                                    ↑
                                                          PCブラウザ(遠隔) ──────────┘
```

- **機体側（Jetson）**: `real/`（cockpit.py ほか）＋ `deploy/` ＋ `model/` ＋ `motions/`
  - DDS はループバック（`--iface` なし → `ChannelFactoryInitialize(0)`）
  - HTTP は `0.0.0.0:8090` で待受
- **PC側**: ブラウザで `http://<機体IP>:8090` を開く。操作・画面は従来と同一。

## 2. 配備

1. `real/`・`deploy/`・`model/`・`motions/` を機体へ `scp`/`rsync` でコピー。
2. 機体側でセットアップ:
   ```bash
   bash setup_onboard.sh
   ```
   （venv 作成 → `requirements_jetpack.txt` 導入 → JetPack 用 torch を NVIDIA index から導入）
3. torch の導入で失敗する場合: `setup_onboard.sh` の `--index-url` では NVIDIA index
   だけを参照する。NVIDIA index に torch の依存（sympy 等）が無い環境では、
   行末に `--extra-index-url https://pypi.org/simple/` を足す。

## 3. 起動

事前に**送信しない・読むだけ**の確認を行う（`--iface ""` がループバック）:

```bash
python3 real/listen_only.py --iface ""
python3 real/probe_version.py --iface ""
```

`listen_only.py` で LowState の数値が流れ、`probe_version.py` で FW 世代が判定できたら起動:

```bash
source .venv/bin/activate
python3 real/cockpit.py     # --iface なし = ループバック DDS
```

PC ブラウザで `http://<機体IP>:8090` を開く。

ループバック DDS がモーションコントローラに届かない場合は、CycloneDDS の
domain/transport 設定（`CYCLONEDDS_URI`）を追加して調整する。

## 4. 安全（遠隔運用の注意）

- **UIハートビート**: ブラウザが毎秒 POST し、**3秒途絶で自動 damp**。
  `--heartbeat-sec 0` で無効化できる（localhost 検証用）。
- **コックピットのタブを前面に保つこと**。ブラウザはバックグラウンドのタブで
  タイマーを間引く（最大約1分間隔）ため、タブを隠すと誤って damp しうる。
  タブを切り替えて作業する現場では `--heartbeat-sec` を伸ばすか、監視は
  `twin.py` 等の別画面で行う。
- 物理 E-stop ＋ ガントリーは従来どおり**最上位の安全層**。ソフトの damp は
  その代替にならない。
- 既存の安全7層（傾き40°・関節速度・LowState断・送信断・目標ガード等）は
  機体側でそのまま動く。

## 5. 検証

1. 機体上で `python3 real/cockpit.py --sim` による全手順リハーサル（ループバック
   DDS 以外を検証）。
2. PC から `http://<機体IP>:8090` 到達・E-STOP・ブラウザ閉鎖による3秒自動 damp を確認。
3. 実機投入は `real/COCKPIT.md` §6 のチェックリスト（probe_version → preflight →
   吊りテスト → 接地確認 → 単体 → 通し）に従う。
